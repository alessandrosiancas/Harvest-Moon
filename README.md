# Harvest Moon 2D (Java Edition)

**Programmazione di Interfacce Grafiche e Dispositivi Mobili**

## Descrizione
Versione semplificata del videogioco per console SNES *Harvest Moon*, con gestione dell'interfaccia grafica (GUI), loop di gioco, e riproduzione di alcune dinamiche di gioco.

## Autori
- **Luis Alessandro Siancas Curi** - [@alessandrosiancas](https://github.com/alessandrosiancas)
- **Francesca Moretti** - [@francycesca](https://github.com/francycesca)

## Struttura e Configurazione
- `src/`: codice sorgente Java e risorse multimediali (sprite, audio, texture).
- `objects.txt`: configurazione e posizioni predefinite degli oggetti nel mondo.
- `config.txt`: salvataggio dello stato giocatore (coordinate, monete, giornata corrente, inventario).
- `configObjects.txt`: salvataggio delle modifiche al mondo (raccolta/posizionamento di piante e oggetti).

## Come eseguire il gioco
1) Dal codice sorgente, eseguire il file presente in `src/java/main/Main`.
2) Dalla sezione **Releases** scaricare il file `Harvest Moon.jar` ed aprirlo.
